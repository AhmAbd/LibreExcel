## [0.1.0] - 2026-11-08

First public release.

### Added

- Excel-style interface: ribbon with Home, Insert, Page Layout, Formulas, Data, Review, View and Help tabs, contextual Table Design and Chart Design tabs, formula bar with Name Box, sheet tabs and status bar
- Backstage File view with Home, New, Open, Save, Save As, Print, Export, Info and About pages
- Formula engine with 400+ Excel functions, dynamic arrays, `LET` and `LAMBDA`
- Excel number formats and the Format Cells dialog
- Cell styles, Format as Table and conditional formatting (highlight rules, color scales, data bars, icon sets)
- Sort, AutoFilter, Remove Duplicates, Subtotals, Data Validation and PivotTables
- Column, bar, line, area, pie, doughnut and scatter charts, and sparklines
- Freeze Panes, cell Notes, Find and Replace, Go To
- Open and save `.xlsx` and `.ods`, import and export CSV and tab-separated text
- Print preview, Page Setup and Export as PDF
- Undo and redo, recent files and AutoSave
