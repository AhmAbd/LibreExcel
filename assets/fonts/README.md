# Bundled fonts

Tabula bundles these fonts so documents look the same on every system. They are
third-party fonts and are not covered by the project's MIT License.

| Font | Purpose | License |
|---|---|---|
| Carlito | Metric-compatible with Calibri | SIL Open Font License 1.1 |
| Liberation Sans | Metric-compatible with Arial | SIL Open Font License 1.1 |
| Liberation Serif | Metric-compatible with Times New Roman | SIL Open Font License 1.1 |
| Liberation Mono | Metric-compatible with Courier New | SIL Open Font License 1.1 |
| Noto Sans, Noto Sans Symbols 2 | UI text and symbol fallback | SIL Open Font License 1.1 |

Sources:

- Carlito: <https://github.com/googlefonts/carlito>
- Liberation fonts: <https://github.com/liberationfonts/liberation-fonts>
- Noto fonts: <https://github.com/notofonts>

The full license text is at <https://openfontlicense.org>.
